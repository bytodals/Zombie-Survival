# Zombie Survival Camp API

Backend REST API for managing a post-apocalyptic zombie survival training camp.

## Knowledge Domain

A system that manages participants, courses, weapons, and zombie behaviors in a simulated survival camp environment.

## Features

- RESTful API with JSON responses
- Connected to MySQL database
- Clean, layered architecture
- Graceful shutdown support
- Written in TypeScript + ESM

## Tech Stack

- Node.js + Express
- TypeScript
- MySQL
- mysql2/promise
